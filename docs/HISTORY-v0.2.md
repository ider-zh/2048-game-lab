# 历史记录：v0.2（后续状态见根目录 HANDOFF）

# HANDOFF — 2048 Lab v0.2

2026-10-15。本次针对“到五百多停止”的反馈，已完成复现、算法升级和状态/容错修复。目录：本地项目目录。预览：http://127.0.0.1:5178 。刷新页面加载 v0.2；默认 Agent A 为 Expectimax 推荐策略，B 为快速启发式。

## 诊断结论

用户所用策略和“五百多”指总分还是砖值尚未知，不能断言准确重现用户原局。旧版六策略各跑 seeds 9000–9004 完整局，共 30 局；全部停止时无合法动作，没有无效动作退出或步数上限退出。旧启发式分别止于 512、1024、256、512、256。没有 512 或 2048 强制结束代码。

发现并修正的实际问题：原启发式对大砖秩序保护偏弱；原 Expectimax 预算按遍历顺序局部截断，使部分方向获得深层估值、其他方向混入浅层估值；暂停显示“待命”，终局缺少原因说明。原 Worker 错误已有提示，但缺少可持续合法动作回退。

## 修改

- 启发式增加秩平方单调性、可合并对奖励与更强空格权重；大砖角落结构更受重视。分项与课堂代码同步更新。
- Expectimax 改为迭代加深，只有四方向中的全部合法动作完成一整层才提交；耗尽预算保留上一完整层，第一层预算不足时显式回退启发式。所有空位与 2/4 概率完整计算，不重新定义游戏规则。
- 默认预算 1600→6000，深度 2→3。预算只限制一次搜索，不结束游戏；显示实际完成深度。
- 严格区分待命、计算中、运行中、已暂停、无合法动作终局、计算失败及降级运行。真正终局显示总分与最大砖。
- Worker 错误、无效/null 动作、15 秒超时终止坏 Worker；正在运行的游戏使用首个合法方向应急推进，暂停时可应急单步，恢复按钮重建 Worker。异常不伪装正常终局。代次标识继续防旧响应/定时器覆盖重置。
- 回放记录真实所用策略、算法版本与回退原因；应急方向记录为 emergency-legal。兼容 agents-1 老回放，新策略版本 agents-2。
- 批量评测每 100 步发送活跃进度，结果带 stopReason、remainingLegal、fallbacks。20,000 步安全上限保留并单独标记，不作正常终局。
